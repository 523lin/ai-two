# 林安 · 个人主页（第一版原型）

深空星夜风格的个人主页原型：深色星空、科技蓝字体、日系漫画风方框眼镜头像，并保留个人信息、正在做的事与可直接演示的数字分身聊天区。

## 导出并在本地运行

这是一个纯静态站点。整个 `lin-an-home` 文件夹就是完整项目，不需要 `npm install`，也不需要构建。

### 方式 A：直接双击打开（最快）

1. 项目已放在 `D:\lin-an-home`，也可以把整个文件夹复制到其他位置。
2. 双击文件夹里的 `index.html`，用 Edge / Chrome 打开即可。
3. 整站可以离线运行，数字分身问答、星场和复制邮箱都不依赖服务器。

注意：

- 不要只复制 `index.html`，`assets` 文件夹必须一起保留。
- 不要把 `assets` 改名，也不要改变 `index.html` 与它的相对位置。
- 不要在 ZIP 压缩包的预览窗口里直接双击，先完整解压。

### 方式 B：本地静态服务器（推荐，便于调试）

在项目文件夹中打开 PowerShell，执行：

```powershell
cd "D:\lin-an-home"
python -m http.server 8000
```

然后浏览器打开 `http://localhost:8000`。停止服务器按 `Ctrl + C`。

如果电脑没有 Python，也可以用：

- VS Code 安装 Live Server 插件，右键 `index.html` → `Open with Live Server`
- 或安装 Node.js 后执行 `npx serve .`

手机端适配已内置：在浏览器开发者工具中切换到 390 × 844 等尺寸即可查看。

## 如何修改

### 1. 联系方式（优先替换）

联系方式统一维护在 `assets/app.js` 第 4 行：

```js
var EMAIL = "hello@linan.example";
```

把 `hello@linan.example` 改成真实邮箱即可。页面里的邮件按钮、邮箱展示、复制按钮和数字分身的回答会一起更新。

> 当前 `hello@linan.example` 是原型占位地址，页面里也做了明确标注。

### 2. 头像

现在用的是 `assets/avatar.svg` 原创日系漫画风头像：正面、棕色短发、方形眼镜、神情沉稳，穿深蓝色高中生制服。它不代表真人长相，只是参考“御幸一也式”日系漫画气质做的原型占位，页面里出现了两次：

- 首屏右侧的大头像
- 聊天窗口顶部和小气泡里的圆形头像

替换成真人照片时，建议使用 4:5 竖图（例如 1200 × 1500），把两个 `<img>` 的 `src` 改为新文件即可。聊天头像会自动裁切，也可以调整 `object-position` 改变取景。

### 3. 页面文案与结构

- 首屏名字、介绍、关注方向：`index.html` 的 `.hero` 和 `.info-bar`
- 关于我与三个关注方向：`#about`
- 最近在做与作品状态：`#now`
- 联系方式：`.contact-card`

当前作品区是“整理中”状态，没有编造不存在的作品。等作品真正上线后，可以把 `.works-panel` 替换成作品卡片列表。

### 4. 数字分身

数字分身的设置集中在 `assets/app.js`：

- `ANSWERS`：每一类问题的回答文案
- `INTENTS`：用于识别问题的关键词与正则
- 底部 `data-question` 按钮：聊天区里的快捷问题（在 `index.html` 中）

当前版本是**纯前端预设问答**：

- 不联网、不调用大模型
- 输入不会发送到任何服务器
- 能回答“现在在做什么 / 有哪些作品 / 怎么联系 / 擅长什么”等已写好的主题
- 遇到没有覆盖的问题会明确说“没有被喂到足够信息”，不编造回答

后续要接真实大模型时，可以保留现有聊天 UI，把 `sendQuestion()` 里的预设回答替换成后端接口请求，并在服务端补上：

1. 林安的公开资料库
2. 检索增强（RAG）与引用来源
3. 敏感问题拒答与人工兜底
4. 限流、日志和隐私说明

## 设计说明

- **颜色**：深空底色 `#02050d`，科技蓝 `#3f8cff`，冷青高光 `#69e2ff`，文字使用蓝灰阶
- **字体**：标题使用 Bahnschrift / Microsoft YaHei 组合，英文小标签使用等宽字体；不依赖外部字体
- **关键内容**：姓名、主标题、区块标题使用蓝白渐变与冷光，重要按钮和状态使用高亮青蓝
- **星空**：由 `app.js` 生成 168 颗不同大小、亮度和闪烁节奏的星点，另有少量十字星与低亮度流星；手机端自动减量
- **布局**：首屏突出“人”，第二屏讲清“关注什么”，第三屏直接用聊天建立连接，最后是正在做的事与联系方式
- **动效**：只保留星点呼吸、少量流星、首屏入场、消息进入和输入状态，尊重 `prefers-reduced-motion`
- **响应式**：在 920px、700px、390px 附近做了布局收敛；320px 宽度下也没有横向滚动
